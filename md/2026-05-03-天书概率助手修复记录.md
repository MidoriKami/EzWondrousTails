# 2026-05-03 天书概率助手修复记录

## 背景

今天对 `E:\git\EzWondrousTails` 中的 `WondrousTailsSolver` 插件进行了兼容性修复、界面调整和中文化整理，目标是让插件能够在当前 `hooks/dev` 环境下正常编译、正常加载，并先通过主窗口稳定显示天书概率信息。

## 今日完成内容

### 1. 修复编译与加载问题

- 修复了 `ImGuiNET` 引用不兼容的问题，改为使用当前环境可用的 `Dalamud.Bindings.ImGui`。
- 适配了当前 `hooks/dev` 环境下的 UI 打开逻辑。
- 去掉了会在运行时触发 `WindowSystem.AddWindow(...)` 缺失异常的实现方式，改为更保守的窗口绘制方案。
- 当前命令验证结果：

```powershell
dotnet build .\WondrousTailsSolver.sln -c Debug
```

构建结果为 `0 warning / 0 error`。

### 2. 修复插件扫描与输出清单

- 调整了 `WondrousTailsSolver.csproj`，补全并修正了插件元数据。
- 输出目录统一到 `WondrousTailsSolver/output/`。
- 生成的 `WondrousTailsSolver.json` 已包含 `Tags` 等扫描所需字段。
- `DalamudApiLevel` 已调整到 `15`。

### 3. 主窗口支持实时显示概率

- 增加了主窗口和设置窗口：
  - `WondrousTailsSolver/Ui/MainWindow.cs`
  - `WondrousTailsSolver/Ui/ConfigWindow.cs`
- 主窗口现在可以显示：
  - 已贴贴纸数量
  - `[胡思乱想]点数`
  - `1线 / 2线 / 3线` 概率
  - `重排平均`
  - 当前 4x4 棋盘状态
- 这样即使原始天书界面节点注入在当前版本下不稳定，仍然可以先通过插件主窗口查看结果。

### 4. 中文化与命名调整

- 插件可见名称调整为：`天书概率助手`
- 主窗口和设置窗口均已改为中文显示。
- 插件介绍补充为“中文在上，英文在下”的双语形式：
  - `Punchline`
  - `Description`
- 为避免源码编码导致中文乱码，界面字符串和输出清单中关键中文内容已尽量改为稳定写法或 Unicode 转义。

### 5. 默认窗口尺寸调整

- 主窗口默认首次大小改为：`350 x 300`
- 设置窗口默认首次大小改为：`350 x 300`
